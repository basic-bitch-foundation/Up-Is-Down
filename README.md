# Up Is Down
## Game Play
In this game Player is constantly running on right side on floor by default, you have to flip the direction of gravity
so that player don't fall in the gaps b/w floor and ceiling!

## Control 
U can flip gravity using space key!

## Installtion
You don't need to install the game, try in browser [HERE](https://basic-bitch-foundation.itch.io/up-is-down)
